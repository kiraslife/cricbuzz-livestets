# 🏏⚾ Cricbuzz LiveStats Pro

A comprehensive sports analytics web application built with Python, Streamlit, and SQLite. This platform integrates real-time cricket data via the Cricbuzz REST API and features a robust SQL-driven analytics module solving 25 complex business questions using authentic Cricsheet JSON archives.

🌐 **Live Application:** [View Live Cricbuzz LiveStats Pro Dashboard](https://cricbuzz-livestets.streamlit.app)

---

## 🚀 Key Features
* **🔴 Live Cricket Scoreboard:** Fetches real-time match telemetry from the Cricbuzz REST API and parses it into human-readable scorecards and synced database records.
* **🏆 Player Leaderboards:** Interactive visualizations and bar charts tracking elite run scorers and wicket-takers.
* **🧮 25 Advanced SQL Analytics Engine:** Business intelligence reports covering multi-format comparisons, head-to-head predictions, venue bowling economies, and player form momentum—rendered with automated interactive graphs and metrics.
* **🛠️ Full CRUD Operations:** Secure form-based interface to manage, insert, update, and delete athlete and match records.

## 🛠️ Tech Stack
* **Frontend:** Streamlit (Custom sports-themed UI & styling)
* **Backend:** Python
* **Database:** SQLite (Relational 3NF Schema with Foreign Keys & Indexes)
* **Data Processing & ETL:** Pandas, Custom JSON Parsers
* **API Integration:** Requests, REST API, RapidAPI
